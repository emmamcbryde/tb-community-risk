# Current public TSTin3D audit

Accessed 2026-11-04. This is a public-document audit; no clinical submissions,
personal data, website-code copying or script execution were used. The visible
HTML text, form labels, About equation images, references and disclaimer were
inspected. Dynamic checkbox/options and results generated by scripts were not
reverse-engineered. Source receipts contain access dates and SHA-256 checksums;
raw website code is not committed.

The public calculator states **Version 3.0** and acknowledges modifications since
Menzies 2008. Its static interface identifies TST size, IGRA, age, immigration age,
birth country, regional location, race/ethnicity, Indigenous status, BCG, contact
and medical/radiographic factors. The complete dynamic option lists and exact
output rendering remain unverified. Public About material describes PPV, annual
and cumulative disease risk and INH-hepatitis estimates. This is not a verified
inventory of every executable output.

The About equation image places ethnicity factor e **outside** the PPV fraction:
`PPV_TST=e*pLTBI/(pLTBI+FP_BCG+FP_NTM)`; the other image shows
`pLTBI=1-(1-c)*(1-ARI)^age`. The public text includes e values3.09,3.66 and1.55
in specified US/Canadian categories. Bounds/capping when the expression exceeds1
are not documented. These values and rules are **not implemented** here.

Other documented rules include the historical incidence/49 coefficient, contact
terms .08/.40, size/BCG-specific false-positive values, IGRA-only positive PPV .98,
a negative-only IGRA rule yielding zero when no TST is present, a combined-positive
rule and a .001 baseline disease rate. Recent-contact and recent-infection wording
contains different early-risk descriptions. The cumulative description remains
annual risk times remaining years to80. The documented INH-hepatitis calculation
is insufficient for complete treatment-benefit reproduction. None of these current
rules is imported into the publication-only reference package.

The reference list was accessible directly and includes underlying BCG/NTM,
medical-risk and hepatotoxicity studies. It does not provide a versioned complete
parameter manifest, executable change log, original country/state tables,
immigration rules, combination algorithm or numerical conventions.

The disclaimer asserts copyright, describes a free clinical tool and prohibits
sale/marketing. It limits pediatric applicability and emphasizes clinical judgement.
This is not a permissive source-code licence or redistribution authorization.
The 2008 paper's software-availability footnote does not establish today's terms.
No third-party implementation is redistributed by this project.

**Exact current-version reproduction cannot be established from the audited public
information.** Author-provided versioned code/parameter documentation, test vectors
and explicit reuse terms would be needed. The [author questions](author_questions_m2a.md)
list the missing information; no request has been sent.
