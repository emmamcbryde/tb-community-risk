# SA Health APY LTBI Model Report Package

This folder contains a consolidated draft report package for SA Department of Health / APY Lands review.

Primary Word report: `APY_SA_Health_LTBI_model_report_draft.docx`

Source Word template used: `APY_LTBI_health_economics_report_updated_post_tb.docx`

The package is derived from current repository outputs and does not change model equations, MATLAB logic, Python dynamic model logic, or Streamlit pages.

Subfolders:

- `tables/`: CSV tables copied or derived for report review.
- `figures/`: existing figure files copied for layout review.
- `excel/`: workbook artefacts copied for review.
- `appendices/`: source output notes and supporting appendix files.
