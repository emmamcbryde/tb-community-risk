# Current APY Targeting Curve Figures

These figures replace the older epidemiological targeting figures from the earlier APY planning report.

They were generated from the current Python/APY model backend using the default report settings: N = 1500, nReps = 2000, seed = 1, a 2-year screening window, 20-year follow-up, IGRA testing, and 3HP preventive therapy.

The curves show direct person-level prevention outcomes from the APY model: people screened, TPT starts and completions, infections cured/protected, active TB cases prevented, number needed to screen, number needed to treat, and false-positive treatment.

Downstream transmission benefits are not included. The figures should therefore be interpreted as direct prevention and prioritisation outputs, not full dynamic transmission impact estimates.
